Admin dashboard — Users compartment

SHAPE / HIGH-FI · static mockup · data wiring later

A maintainer/owner-only modal opened from above the Admin notifications rail. Top tabs frame future compartments (Requests, To publish, Permissions); the Users tab is built here — a dense, sortable directory with a per-user detail drawer. Every metric below comes from the SQLite substrate already in the repo, except edits, which is shown as a deferred placeholder. States are stacked so you can scan them in one pass.

1 · Entry point — button above the Admin notifications rail

Reuses the existing $isAdmin gate (maintainers + owners). Primary accent button so it reads as the one action above the passive notification feed.
