Admin dashboard — Requests compartment

SHAPE / HIGH-FI · static mockup · data wiring later
View as:

Requests move out of the notifications rail into their own tab — a review queue, not a feed. Every field comes from the requests table already in SQLite (status · slug · requester · submitted_at · auto_claim · comments · proposed_edits in payload): no schema change, only a batch list read. Click a row to review inline. Toggle View as (top right) to see owner vs. maintainer requester redaction.

1 · Open requests — review inline

Status facets with live counts (dulled when empty, same vocab as the Users role filters). Each row triages on the four things that matter: whose recitation (Arabic name leads, Latin paired), which combination, what they want changed, and how long it has waited. The Maher al-Muaiqly row is expanded.
